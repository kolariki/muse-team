# Muse Team

Tu equipo de IA que diseña y construye apps, powered by Muse.

Escribís una idea. Un equipo de agentes con roles (CEO, CTO, ingeniería, producto, diseño y QA) razona con **Muse Spark** y **Muse Wonder**, la debate, investiga apps de referencia, diseña las pantallas, **Muse Code** escribe el código, el equipo lo revisa y la app se publica con un clic. Además, el equipo arma los anuncios con **Muse Voice Transcribe** y trabaja sobre **Meta Ads**.

## Arranque rápido

```bash
cp .env.example .env
make install
make dev                    # backend :8000 + frontend :5173
```

Abrí http://localhost:5173, creá tu cuenta y cargá tu key de Meta en **Modelos y API keys**. Sin key, el equipo trabaja en modo simulado.
